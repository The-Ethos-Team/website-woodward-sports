# Woodward Sports Network — Sitemap (Next.js)

Multi-page structure for the Woodward 2.0 Digital Hub, built from the one-page preview.
The brief's priorities drive the order: Sports prominent → find a team / show / story fast →
clear Watch / Listen paths → commercial + sponsor touchpoints.

## Global (on every page)
- **Header**: logo, ON AIR / UP NEXT status pill (America/Detroit), nav (Shows · Teams · Stories · Watch · Listen · Shop · Advertise), Find (⌘K / "/"), Watch Live button
- **Mobile dock**: Shows · Teams · [WATCH / LIVE] · Listen · Shop
- **Find overlay**: search across shows, teams, stories, videos
- **Live Room**: one YouTube player (live stream when on air, replays otherwise), minimizable mini player that persists across page navigation
- **Footer**: "Sound off." socials, nav, app link, privacy

## Data layer (Vercel, revalidated, no database needed)
- Stories, categories, authors: `woodwardsports.com/wp-json/wp/v2/*` (ISR, ~10 min)
- Videos: YouTube channel RSS (ISR, ~10 min); live/replay embed by schedule
- Podcasts: Spreaker RSS feeds (ISR, ~1 h)
- Merch: `shop.woodwardsports.com/products.json` (ISR, ~1 h)
- Schedule, hosts, show copy, sponsor inventory: typed config in the repo
- Every feed falls back to a bundled JSON snapshot if the source is down.
